# Recreate this site as a single HTML file: ReserveUrTime — Momo Hero

## What it is

A full-viewport luxury momo / dumpling hero inspired by premium editorial food photography.
The scene is dark charcoal with subtle burgundy undertones, soft warm steam lighting and an elegant
stone/black ceramic surface.

Several real steamed momos float in depth around one central hero momo. The surrounding momos remain
whole. The center momo performs the signature reveal: its pleated wrapper, upper shell, seasoned
filling, herb layer and lower wrapper separate gently while preserving the exact real photographed
momo identity.

The mood is quiet, tactile and handcrafted — steam, pleats, moisture, filling texture, shadow, no
cartoon effects.

```html
<meta charset="UTF-8">

<script src="https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.5/gsap.min.js"></script>
```

Global reset:

```css
* { margin:0; padding:0; box-sizing:border-box; }
html, body { width:100%; min-height:100%; }

  font-family:'DM Sans',sans-serif;

```

The hero is exactly one viewport high:

```css
.hero {
  position:relative;
  width:100vw;
  height:100svh;
  min-height:720px;
  overflow:hidden;
  isolation:isolate;
}
```

Inside the hero use:
1. atmosphere/background layer,
2. ambient particles/steam/smoke layer,
3. left editorial copy,
4. center/right food stage,
5. small premium controls,
6. depth shadows,
7. optional decorative foreground particles.

Do NOT include a site-wide navbar. This hero will later be embedded as one full-height section inside
the ReserveUrTime homepage.

## Assembled state

Central momo:
- slight 3/4 facing camera.
- rotateX `4deg`, rotateY `-7deg`, rotateZ `1deg`.
- soft contact shadow beneath.
- tiny moisture highlight via supplied photo only, not painted with CSS.

Whole supporting momos:
- positions around stage, never forming a perfect circle.
- each has subtle drop shadow and depth blur only when far background.
- background momos opacity .75–.92.

## Explode state

Button: `OPEN THE FOLD` and `CLOSE`.

On open:
1. central rig scale 1 → 1.035 over .25.
2. pleated crown: y `-170px`, x `+4px`, z `+76px`, rotateZ `+4deg`.
3. upper wrapper: y `-96px`, x `-5px`, z `+52px`, rotateZ `-3deg`.
4. filling: y `-6px`, x `+3px`, z `+24px`, rotateZ `+1.5deg`.
5. herbs: y `+72px`, x `-5px`, z `+8px`, rotateZ `-3deg`.
6. lower wrapper: y `+148px`, x `+4px`, z `-18px`, rotateZ `+2deg`.
7. duration `1.15`, stagger `.07`, ease `"power3.inOut"`.

Supporting whole momos:
- drift outward by 12–30px as the center opens.
- do not explode.
- opacity remains > .72.

Dipping bowl:
- shift 10px right and rotate -1deg during open.

## Steam

Steam is central to this hero.

Create 7–10 steam wisps from:
- central momo,
- 2 nearby whole momos,
- dipping bowl only if visually appropriate.

Each wisp:
- narrow curved-ish blurred gradient or supplied PNG;
- opacity .05–.18;
- rise 120–260px;
- drift X -30…+30px;
- duration 5–9s;
- slight scale growth;
- no thick grey smoke.

Pointer can bend steam direction subtly:
`steamDrift += mouseX * 12px`.

## Pointer / depth parallax

Smooth mouse with .05.

Central momo rig:
- rotateY base -7 + mouseX*6deg;
- rotateX base 4 + mouseY*-3deg;
- translateX mouseX*10px;
- translateY mouseY*6px.

Supporting momos:
- near layer parallax 20px;
- mid 12px;
- far 6px.

Coriander pieces:
- 24–34px parallax, tiny rotation.
- do not follow cursor like UI icons.

## Lighting

- use a large blurred pseudo-element behind/over stage;
