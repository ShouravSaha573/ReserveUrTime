# ReserveUrTime — Premium Food Hero Prompt Pack

This pack contains four detailed hero-section generation prompts designed to match the level of
specificity and implementation detail of the supplied `Hero_Section` Soda prompt.

Files:
- `Burger_Hero_Section.txt`
- `Pizza_Hero_Section.txt`
- `Momo_Hero_Section.txt`
- `Kebab_Hero_Section.txt`

These prompts are deliberately designed around REAL photographic food layers and premium motion.
They explicitly prohibit image generation, cartoon assets, emojis and fake primitive food geometry.

Recommended homepage order:

1. ReserveUrTime clean introductory hero
2. Burger full-height hero
3. Pizza full-height hero
4. Momo full-height hero
5. Kebab full-height hero
6. Soda full-height hero using the original supplied `Hero_Section`
7. Restaurant discovery/search
8. Restaurant listing
9. Footer

Important:
- Each section should occupy its own viewport-sized block.
- Do not compress these heroes into one rounded preview card.
- Food assets should be high-resolution transparent PNG/WebP layers derived from the same real
  photograph or photo set for that dish.
- The supplied Soda prompt remains unchanged and authoritative for Soda.
- No image generation is performed or required by this pack.
