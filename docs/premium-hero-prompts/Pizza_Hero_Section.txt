# Recreate this site as a single HTML file: ReserveUrTime — Pizza Hero

## What it is

A full-viewport premium artisan pizza hero built from real photographic layers. The mood is a dark,
cinematic oven environment: almost-black background, deep tomato-crimson glow, a gentle amber
oven-light sweep, floating flour dust and tiny embers.

A photorealistic whole pizza hovers in a subtle 3/4 perspective. The hero starts assembled. When
`EXPLORE LAYERS` is triggered, the SAME pizza separates upward in controlled depth layers:
fresh herbs/toppings, primary topping layer, mozzarella, tomato sauce, crust/base. The pizza remains
circular, aligned and recognizably the same object. `ASSEMBLE` reconnects all layers precisely.

No cartoon pizza, no low-poly geometry, no flat colored discs, no exaggerated flying slices.

```css

  position:absolute;
```

The pizza visual should occupy roughly 520–760px desktop diameter, with a 3/4 tilt:

- rotateZ `-8deg`

## Explode geometry

Unlike burger, pizza separates mostly along its local normal axis so layers feel like lifting from
the baked base while the whole pizza remains in 3/4 perspective.

Store assembled transforms first.

On `EXPLORE LAYERS`:
- rig scale 1 → 1.025 over .28s.
- crust remains near base with local translateZ `0`.
- sauce: translateZ `55px`, tiny translateX `-4px`, rotateZ `-1.5deg`.
- cheese: translateZ `115px`, translateX `+4px`, rotateZ `+2deg`.
- toppings: translateZ `185px`, translateX `-6px`, rotateZ `-2.5deg`.
- herbs: translateZ `245px`, translateX `+7px`, rotateZ `+3deg`.
- duration `1.25s`, stagger `.075s`, ease `"power3.inOut"`.

Because the rig itself is tilted, the separation should read as a beautiful vertical-depth stack.

Do not flatten perspective when exploded.

## Cheese stretch

Create 3–5 optional `cheese-thread` elements only if `PIZZA_CHEESE_THREAD_PNG` or SVG thread assets
are supplied.

Behavior:
- appear between crust/cheese during the first 45% of explode.
- scaleY from .3 to 1.0 as cheese lifts.
- opacity peaks at .65.
- at 70% transition, threads thin and fade.
- on assemble reverse briefly.
- subtle only; no giant cartoon mozzarella strings.

If no thread asset is supplied, do not fake large cheese strings with thick CSS shapes.

## Pizza rotation / pointer

Idle:
- rotateZ oscillation ±1.2deg over 7s.
- rig bob in screen Y ±6px.
- tiny perspective breathing: scale 1 → 1.01 → 1.

Pointer:
- screen-space translate X mouse*10px;
- translate Y mouse*7px;
- additional rotateZ mouseX*2.5deg;
- rotateY mouseX*3deg;
- rotateX base 56deg + mouseY*-2deg.
- toppings local parallax slightly stronger than crust.

Do not allow user drag/orbit; this is a curated hero camera.

## Oven-light sweep

Add a pseudo-element `.heat-sweep` behind pizza:
- elliptical blur 90px;
- amber-to-transparent gradient.
- once every 6–8s sweep left→right behind the pizza.
- opacity max .16.

## Flour + ember particles

Create 22–36 lightweight DOM particles:
- 70% flour: warm white, 1–3px, opacity .08–.28.
- 30% ember: orange, 1–2px, opacity .18–.5.
- slow rising/diagonal drift.
- depth layers: background, mid, foreground.
- pointer parallax based on depth.
- no particle should look like a star field.

## Lighting / shadows

Each layer gets:
```css
filter: drop-shadow(0 24px 40px rgba(0,0,0,.38));
```
but adjust by depth:
- deeper base shadow stronger/softer.
- herbs minimal shadow.
- exploded state adds a second small contact shadow beneath each lifted layer.

Do not add outlines around pizza layers.
