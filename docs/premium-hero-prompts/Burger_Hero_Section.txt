# Recreate this site as a single HTML file: ReserveUrTime — Burger Hero

## What it is

A full-viewport luxury burger hero. A hyper-realistic gourmet burger floats in a dark charcoal,
espresso and warm amber environment. The burger initially appears fully assembled and looks like a
high-budget food photography campaign: toasted brioche bun, real sesame seeds, crisp lettuce,
tomato, pickles/onion where supplied, glossy melted cheese, deeply grilled beef with visible char
and moisture, sauce, and a toasted bottom bun.

The signature interaction is a controlled, premium "ingredient reveal". When the user clicks
`EXPLORE LAYERS`, the exact same burger separates vertically into its photographic ingredient layers.
The layers stay aligned to the original burger silhouette and retain the same photography,
perspective, lighting and scale. They do not fly randomly around the screen. `ASSEMBLE` reverses the
motion precisely.

The burger subtly tracks the pointer using 3D parallax. Steam drifts upward. A few sesame seeds,
pepper specks and herb flecks float in shallow depth. Shadows between ingredients deepen during the
exploded state. The mood is refined, cinematic, warm, appetizing and realistic.

Create this exact DOM layer order:


Only include layers for assets that actually exist. If the supplied burger has fewer components,

Each image:

- use `translate3d(x, y, z)` and not absolute `top` changes for animation;
- each layer may have a tiny individual `rotateZ` between -1.5° and +1.5°.

## Exploded state choreography

Control:
```html
<div class="view-toggle">
  <button class="active" data-mode="explode">EXPLORE LAYERS</button>
  <button data-mode="assemble">ASSEMBLE</button>
</div>
```

The hero loads assembled.

When `EXPLORE LAYERS` is clicked:
1. 0.00–0.25s: entire burger rises `-10px`, scales `1.015`.
2. 0.12–1.45s: ingredient layers separate vertically with stagger `0.055s`.
3. top bun target: y `-260px`, x `+8px`, z `+84px`, rotateZ `+4deg`, rotateX `-2deg`.
4. top lettuce: y `-170px`, x `-12px`, z `+66px`, rotateZ `-3deg`.
5. tomato: y `-105px`, x `+12px`, z `+46px`, rotateZ `+3deg`.
6. cheese: y `-42px`, x `-8px`, z `+28px`, rotateZ `-4deg`.
7. patty: y `+32px`, x `+5px`, z `+10px`, rotateZ `+2deg`.
8. pickle/onion group: y `+102px`, x `-10px`, z `-8px`, rotateZ `-3deg`.
9. bottom bun: y `+185px`, x `+5px`, z `-26px`, rotateZ `+2deg`.
10. use `duration:1.15`, `ease:"power3.inOut"`.
11. ingredient inter-layer shadows intensify as distance increases.
12. add a soft 0.4s glow sweep behind the burger during the transition.

The exploded burger must still read as ONE vertical burger composition.

When `ASSEMBLE` is clicked:
- reverse all layers to exact stored assembled transforms;
- duration `1.05`;
- stagger from bottom to top `0.045`;
- ease `"power3.inOut"`;
- at completion reduce burger rig scale to 1.

Do not:
- scatter ingredients more than ~22px horizontally;
- rotate any food layer beyond 6deg;
- make ingredients spin 360deg;
- invent ingredient layers;
- morph food textures;
- add fake 3D cubes/planes around the burger.

## Pointer interaction

Track pointer as normalized `[-.5,.5]`.

Smooth with lerp factor `.055`.

Per frame:
- entire burger rig rotateY = mouseX * 7deg;
- entire burger rig rotateX = mouseY * -4deg;
- translateX = mouseX * 12px;
- translateY = mouseY * 8px.
- food layer local X parallax = mouseX * `(depth / 84) * 8px`.
- local Y parallax = mouseY * `(depth / 84) * 5px`.
- copy column parallax <= 4px.
- foreground sesame/pepper particles parallax 20–32px.

If `prefers-reduced-motion`, disable pointer tilt and continuous floating; the buttons should still
switch assembled/exploded states with a short opacity/translate transition.

## Idle motion
