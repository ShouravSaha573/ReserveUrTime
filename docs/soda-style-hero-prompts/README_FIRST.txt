# ReserveUrTime — Soda-Style Food Hero Prompt Pack

These four prompts were redesigned from the structure and motion language of the supplied Soda
`Hero_Section` prompt.

Important:
- They do NOT use Burger/Pizza/Momo/Kebab JPG, PNG, or WebP hero images.
- They do NOT use exploded-layer / assemble interactions.
- They do NOT image-generate assets.
- Each hero expects a realistic intact GLB/GLTF food model plus realistic 3D floating prop assets.
- The sections follow the Soda-style composition:
  giant editorial copy + central 3D product + floating depth props + pointer parallax + repulsion +
  right-side two-card selector + full-theme transition + giant secondary headline.
- These are standalone full-viewport sections meant to be embedded into the ReserveUrTime homepage.

Recommended homepage order:
1. ReserveUrTime Intro
2. Burger hero
3. Pizza hero
4. Momo hero
5. Kebab hero
6. Soda hero
7. Search
8. Restaurants
9. Footer
